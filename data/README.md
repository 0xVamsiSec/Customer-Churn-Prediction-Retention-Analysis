# Dataset attribution

`raw/customer_churn.csv` is the unmodified public [IBM Telco Customer Churn sample](https://github.com/IBM/telco-customer-churn-on-icp4d/blob/master/data/Telco-Customer-Churn.csv). Its SHA-256 is `16320c9c1ec72448db59aa0a26a0b95401046bef5d02fd3aeb906448e3055e91`.

The processed CSVs repair blank charges, encode the historical outcome, and add engineered features. The Power BI dataset and prediction CSVs add scores from this project’s model to the sample records.
